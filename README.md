
# 🌸 Sakhi AI - Your Unchanging Anchor

**Sakhi** (meaning a true companion) is an empathetic, stable, and judgment-free web companion engineered to offer comfort, validation, and emotional strength to individuals navigating loneliness or academic anxiety. 

Unlike cold, generic chatbots, Sakhi's system architecture is strictly locked into a spectrum of positive, warm, and uplifting validation—creating a permanent digital refuge where users can confide their deepest thoughts without fear of changing loyalties or social judgment.

## 🧠 System Architecture & Evolution

### Phase 1: Local Python & Vision Prototyping
The concept originally launched as a Python system utilizing **Google GenAI SDK** and computer vision layers via **Google Teachable Machine**. 
* Visual modules (`keras_model.h5`) and Audio layers (`BROWSER_FFT`) were mapped out to dynamically calculate user distress vectors based on voice frequencies, pacing, and facial matrix tracking.

### Phase 2: Production Client Refactoring (The Gemini API Pipeline)
To ensure absolute accessibility across all desktop displays, iPhones, and Android web-views without being blocked by browser hardware restrictions, Sakhi was upgraded to an asynchronous web console connected directly to the **Google Gemini 2.5 Flash API Engine**.
* **State Memory Array:** The interface tracks full conversation arrays (`conversationHistory = []`) to ensure deep contextual continuity.
* **Strict Behavioral Guardrails:** The front-end leverages advanced persona alignment strings to enforce zero-negative feedback paths.

## 🛠️ Installation & Setup

Since Sakhi runs as a single-page client-side web application, you can host her locally or deploy her to any cloud platform within seconds.

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   cd Sakshi-The-caring-AI
   ```

2. **Configure Your Secret Key:**
   * Generate a free API credential from **[Google AI Studio](https://google.com)**.
   * Open `index.html` in your text editor.
   * Locate **line 85** and paste your string:
     ```javascript
     const API_KEY = "PASTE_YOUR_AI_STUDIO_API_KEY_HERE";
     ```

3. **Launch Locally:**
   * Simply double-click `index.html` to load the application inside Google Chrome, Safari, or Microsoft Edge.
